# FINTRACE AI — Beyond the Numbers

Track C: Consumer, FMCG & Retail | ATMOS 2026, BITS Pilani Hyderabad

A Streamlit research **prototype** demonstrating public HTML evidence retrieval, document excerpts, transparent price/mix and receivables calculations, and a counter-hypothesis checklist.

## Deploy on Streamlit Community Cloud

1. Open https://share.streamlit.io and sign in with GitHub.
2. Choose repository `giaamadan2027/bitspilani-comp`, branch `main`, main file `app.py`.
3. Deploy. No API secrets are needed for this version.

## Limitations

This is not yet a fully autonomous investigative agent. It does not automatically discover arbitrary company source URLs, independently triangulate sources, parse scanned PDFs, or autonomously falsify hypotheses. Figures should be cross-checked with primary disclosures.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
